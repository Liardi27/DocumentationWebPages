En este trabajo de guía de viaje de mi pueblo pais etc.. quería hacerlo de un sitio que fuera bonito visitar, por ejemplo el pueblo de Hallstat, que es un pueblo de Austria. Ya que mi bonito pueblo llamado Ciempozuelos no tiene nada prácticamente, por lo tanto he querido hacer la guía de viajes del pueblo más bonito del mundo (o eso dicen) para compensar un poquito. 

Le pedí a ChatGPT que me hiciera un prompt con algunas de las cosas que yo tenía pensado, por lo qué se lo pedí y me dio un resultado bastante bueno, aquí está mi prompt final:
<< 

Prompt definitivo para Gemini

Actúa como un desarrollador web con más de 30 años de experiencia en la creación de aplicaciones web interactivas, funcionales y visualmente atractivas, utilizando HTML, CSS y JavaScript puro (Vanilla JS), sin frameworks ni librerías externas.

Desarrolla una aplicación web completa, inmersiva e interactiva que funcione como una guía de viajes del pueblo real de Hallstatt (Austria), famoso por su lago, montañas, arquitectura alpina y ambiente histórico.

La aplicación debe ofrecer una experiencia visual moderna, fluida y envolvente, con animaciones, transiciones suaves y una interfaz organizada que invite al usuario a explorar.

🎯 Objetivo general

Crear una aplicación turística completa y bonita, con navegación fluida, contenido real y una base de datos local con IndexedDB para guardar, importar y exportar datos de usuario.

🧩 Estructura y archivos

La aplicación debe estar organizada en:

Contenido y funcionalidades principales:

  1. Encabezado y navegación fija:

    • Barra de navegación superior con el título “Guía de Hallstatt” y enlaces a las secciones: Inicio, Lugares, Galería, Historia, Gastronomía, Contacto.

    • El encabezado debe permanecer visible al hacer scroll.

  2. Sección de bienvenida (Inicio):

    • Imagen panorámica de Hallstatt como fondo.

    • Texto de presentación con el mensaje: “Descubre la joya de los Alpes: Hallstatt”.

    • Un saludo dinámico según la hora del día (mañana, tarde, noche).

  3. Sección de lugares destacados:

    • Muestra al menos 3 lugares reales de Hallstatt (por ejemplo: el Lago Hallstatt, las Minas de Sal, la Iglesia del pueblo).

    • Cada lugar debe tener una tarjeta con imagen, título, descripción y botón “Ver más”.

    • Al hacer clic en “Ver más”, debe abrirse un modal con más información, imágenes y curiosidades.

  4. Galería de imágenes:

    • Crea un carrusel (slider) en JavaScript puro.

    • Las imágenes deben rotar automáticamente y permitir navegación manual con flechas o puntos indicadores.

  5. Historia y cultura:

    • Breve descripción sobre los orígenes del pueblo, su importancia cultural y patrimonio de la humanidad.

    • Incluye citas o frases inspiradoras de viajeros o locales.

  6. Gastronomía local:

    • Lista con platos típicos austríacos populares en Hallstatt (como schnitzel, goulash, apfelstrudel).

    • Cada plato con una imagen y una breve descripción.

  7. Mapa del pueblo:

    • Imagen estática o mapa representativo (sin usar APIs externas).

    • Incluye marcadores visuales sobre los puntos principales.

  8. Formulario de contacto:

    • Campos: Nombre, Email, Mensaje.

    • Validación con JavaScript (mostrar alertas o mensajes sin recargar la página).

  9. Modo claro/oscuro:

    • Botón tipo toggle que cambie dinámicamente el tema visual.

  10. Base de datos local (IndexedDB):

  • Usa IndexedDB para guardar, importar y exportar datos de forma local.

  • Los datos deben incluir:

    • Lugares visitados por el usuario (nombre, fecha, comentario opcional).

    • Favoritos (sitios que el usuario marque).

  • Incluye botones:

    • “Guardar visita” → almacena un nuevo registro en IndexedDB.

    • “Ver registros” → muestra los datos guardados.

    • “Exportar datos” → descarga un archivo .json con los registros del usuario.

    • “Importar datos” → permite cargar un archivo .json previamente exportado para restaurar los datos en la app.

  1. Animaciones y efectos visuales:

  • Transiciones suaves entre secciones.

  • Efectos al pasar el cursor sobre botones e imágenes.

  • Animaciones en la aparición del contenido (por ejemplo, fade-in o slide-in).

  1. Pie de página:

  • Información del creador.

  • Créditos de imágenes y enlaces sociales.

  • Año actual mostrado dinámicamente con JavaScript.

🧩 Requisitos técnicos adicionales:

  • Código organizado, comentado y con nombres de variables descriptivos.

  • Todo el texto, comentarios y etiquetas deben estar en español.

  • No incluir contenido relacionado con SEO.

  • La app debe ser responsiva (adaptarse a móvil, tablet y escritorio).

💬 Al final, incluye una breve explicación en texto plano describiendo cómo está estructurada la aplicación, cómo se maneja la base de datos IndexedDB y cómo funcionan las funciones de importación/exportación de datos.
