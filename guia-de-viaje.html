Guía de viaje 

Cristina Cichon Klacza
noviembre 18, 2025
Updated on noviembre 20, 2025

En este proyecto he desarrollado una guía de viajes interactiva basada en un lugar real: Hallstatt, un pintoresco pueblo de Austria famoso por su arquitectura alpina, su lago y su entorno montañoso. Aunque inicialmente pensé en hacer la guía sobre mi propio pueblo, Ciempozuelos, decidí centrarme en Hallstatt por su atractivo turístico y sus múltiples recursos visuales, lo que permite crear una aplicación más rica y completa.

Para iniciar el proyecto, pedí ayuda a ChatGPT para generar un prompt detallado en el que recogí mis ideas principales. Tras varias iteraciones, obtuve un prompt final muy sólido que utilicé con Gemini para generar la estructura base de la aplicación. Este es el prompt definitivo que envié:

Actúa como un desarrollador web con más de 30 años de experiencia en la creación de aplicaciones web interactivas, funcionales y visualmente atractivas utilizando HTML, CSS y JavaScript puro (Vanilla JS), sin frameworks ni librerías externas.

Desarrolla una aplicación web completa, inmersiva e interactiva que funcione como una guía de viajes del pueblo real de Hallstatt (Austria).

La aplicación debe ofrecer una experiencia visual moderna, fluida y envolvente, con animaciones, transiciones suaves y una interfaz organizada.

🎯 Objetivo general

Crear una aplicación turística completa y atractiva, con navegación fluida, contenido real y una base de datos local con IndexedDB para guardar, importar y exportar datos de usuario.

🧩 Estructura y funcionalidades

(Lista completa mantenida tal cual: navegación, secciones, galerías, gastronomía, mapa, modo oscuro, IndexedDB, animaciones, pie de página, etc.)

🧩 Requisitos adicionales

  • Código organizado y comentado.

  • Todo en español.

  • Sin contenido SEO.

  • Totalmente responsiva.

Al final, el modelo debe incluir una breve explicación técnica sobre la estructura de la app y el manejo de IndexedDB.

Con la llegada de Gemini 3.0, perdí la opción de seleccionar zonas específicas del código para editarlas, así que tuve que reenviar todo el archivo HTML. Esto provocó que Gemini reestructurara completamente la interfaz, pero para mi sorpresa, el nuevo diseño era aún mejor que el anterior, así que decidí adoptarlo.

La interfaz actual es visualmente más limpia, moderna y organizada. Aun así, quedan algunas funciones por pulir, como adaptar correctamente el apartado “Mi Perfil” y la opción de almacenar datos en la nube es algo más compleja que requiere tiempo y una lógica adicional fuera del alcance del código local.
