Documentación de OmniFile V3
diciembre 12, 2025

¿Cómo está hecha? 

He realizado con Gemini la página OmniFile V3 que es un visor de documentos, pero también puedes editar algunos archivos como, Html, Json, txt, docx, pero no puedes editar PDFS. 

Los prompts que he realizado son: 

Primer Prompt:

<< Actúa como un desarrollador de aplicaciones web con más de 15 años de experiencia. Quiero que diseñes, planifiques y generes el código completo para una aplicación multiplataforma que permita subir y procesar archivos de distintos tipos: Texto (.txt), PDF, Markdown (.md), JSON (.json) y otros formatos comunes. La aplicación debe funcionar en Web, Móvil y Escritorio usando una arquitectura que lo permita (por ejemplo: React + Capacitor, Flutter, Tauri, Electron, etc.).

1. Arquitectura general

Explica y justifica:

Framework principal para lograr multiplataforma (p. ej.: Flutter, React + Capacitor,

React Native + Web, Tauri, etc.).

División Frontend – Backend.

Cómo la aplicación funcionará en:

Navegadores web.

Móviles (Android/iOS).

Escritorio (Windows/Linux/Mac).

Tecnologías recomendadas para el backend (Node.js, FastAPI, etc.).

2. Requisitos funcionales

La aplicación debe permitir:

 

Subir archivos mediante:

Drag & drop.

Selector de archivos nativo según plataforma.

Validar:

Tipo de archivo.

Tamaño máximo.

Procesar cada tipo:

TXT: Mostrar contenido en vista previa.

Markdown: Renderizarlo con estilo.

JSON: Formatear, validar y mostrar árbol.

PDF: Previsualizar (si aplica) o extraer texto.

Guardar archivos temporalmente o en almacenamiento persistente (según plataforma).

UI moderna, clara, responsive y consistente en todas las plataformas.

3. Entregables

Debes generar:

 

Arquitectura completa explicada (capas, flujo de datos, componentes).

Estructura de carpetas del proyecto.

Código del frontend adaptado al framework elegido.

Código del backend con endpoints para subir/leer/procesar archivos.

Explicación del flujo completo:

El usuario selecciona archivo.

El frontend lo valida y lo envía.

El backend procesa y responde.

El frontend muestra el resultado.

Instrucciones de ejecución para:

Web

Móvil

Escritorio

4. Mejoras opcionales que debe proponer

Incluye recomendaciones como:

Autenticación y roles.

Historial de archivos subidos.

Conversión entre formatos.

OCR para PDFs/Imágenes.

Exportación del contenido procesado.

Integración con almacenamiento en la nube. >>
